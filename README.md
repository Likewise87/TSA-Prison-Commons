# TSA Prison Commons

RimWorld **1.7** fork of [Prison Commons (Continued)](https://github.com/emipa606/PrisonCommons) by Ben Lubar / Mlie (MIT).

**GitHub only** — not published on Steam Workshop. Do not run alongside `Mlie.PrisonCommons`.

## Requirements

- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- [ReGrowth 2](https://steamcommunity.com/sharedfiles/filedetails/?id=2260097569) (hard dependency)

Optional soft support: ReBuild Doors and Corners, Dubs Bad Hygiene, Resurrectionem Furniture / VFE cell doors.

## Install

Copy this folder into your RimWorld `Mods` directory (or clone into `Mods`), then enable **TSA Prison Commons** in the mod list after Harmony and ReGrowth 2.

## Build

```bash
dotnet build Source/TSA_PrisonCommons.csproj -c Release
```

Output: `1.7/Assemblies/TSA_PrisonCommons.dll`
